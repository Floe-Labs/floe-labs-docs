# Floe — Onchain Credit Protocol

> Floe is the onchain credit layer and bureau, built for AI agents and backed by institutions. One protocol with three credit tiers: secured (live), receivables-backed (Q3 2026), and uncollateralized agent credit (Q3 2026). Live on Base mainnet. App: app.floelabs.xyz

This file is a structured map of the Floe documentation, optimized for LLM agents reading it as part of a tool loop. Each page can also be queried directly by appending `?ask=<question>` to the URL — the response includes citations.
