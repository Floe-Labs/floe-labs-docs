## Prerequisites

1. **Wallet**: MetaMask, Coinbase Wallet, or any WalletConnect-compatible wallet
2. **Network**: Base Mainnet (Chain ID: 8453)
3. **Tokens**: USDC (loan token) and WETH (collateral)
