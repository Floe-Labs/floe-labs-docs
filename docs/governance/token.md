## Value Capture

### Protocol Fees

Currently, protocol fees flow to the treasury:

```
Match Commission ─────▶ Matcher (off-protocol)
Protocol Fee ─────────▶ Treasury
Liquidation Bonus ────▶ Liquidator (off-protocol)
```

### Future Fee Distribution
