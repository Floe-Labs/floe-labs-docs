# Lend with Floe

1. Choose collateral policy (assets, min LTV, allowed terms).
2. Set rate & amount (e.g., ≥5.25% APR, 30–180d).
3. Add conditions (oracle freshness, price bands).
4. Sign & post (funds stay in wallet until settlement).
5. Monitor, withdraw interest, or auto‑roll via Hook.

**Yield drivers:** rate, term, collateral quality, conditions, Hook fees.
