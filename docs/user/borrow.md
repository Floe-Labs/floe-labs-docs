# Borrow with Floe

1. Select collateral & LTV (e.g., 15 ETH to borrow 20k USDC ~150% collateralized).
2. Pick rate & term (fixed or variable).
3. Optional safeguards (execute only if ETH < $X; min fill 40%).
4. Sign & post; settle and receive funds.
5. Manage top‑ups, early repay, or refi when cheaper.
