# Quick Start

1. **Choose a role:** Lender or Borrower.
2. **Connect wallet:** EOA or ERC‑1271 Safe/multisig.
3. **Create Intent:** Sign EIP‑712 with terms; optional conditions (price, liquidity, time).
4. **Match:** Independent matchers pair intents; best route wins.
5. **Settle:** Single tx escrows lender funds + borrower collateral in an isolated loan.
6. **Manage:** Repay, top‑up, refinance, or roll via app or agent.

> **Testnet:** Base testnet (Q3/4 2025). **Mainnet target:** Base (Q4 2025).
