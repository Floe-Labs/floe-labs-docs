# 05 · x402 payment facilitator `GA`

One proxy endpoint to pay any of **13,000+ x402 APIs**. The Floe facilitator handles signing, settlement, and verification — your agent never touches the x402 protocol directly. Smart-contract enforced spend limits and allowed destinations. **~50ms signing.**

---

## The 6 x402 actions

| Action | Use |
|---|---|
| `grant_credit_delegation` | Provision a managed Floe credit agent (server-managed Privy wallet + on-chain delegation) and mint its `floe_*` API key |
| `revoke_credit_delegation` | Revoke a facilitator's borrowing authority |
| `check_credit_delegation` | Inspect delegation: approved, limits, borrowed, expiry |
| `x402_fetch` | Fetch any URL — automatic x402 payment if the server returns HTTP 402 |
| `x402_get_balance` | Check your x402 credit balance |
| `x402_get_transactions` | List recent x402 payment transactions |

Plus the agent-awareness preflight tool:

| Action | Use |
|---|---|
| `estimate_x402_cost` | Preflight a URL — returns cost + reflection against your current credit, no payment |

## Pay any x402 API

```typescript
const preflight = await agentkit.run("estimate_x402_cost", {
  url: "https://api.example.com/premium",
});
if (preflight.willExceedAvailable) throw new Error("out of credit");

const response = await agentkit.run("x402_fetch", {
  url: "https://api.example.com/premium",
  method: "POST",
  body: { prompt: "..." },
});
```

## How it works

```
Agent → credit-api.floelabs.xyz/v1/proxy/fetch → target API
              ↑                       ↑
        Signs + settles          Returns 402
        on Floe's facilitator
        contract
```

When the target API returns HTTP 402, the facilitator pays from your delegated credit and re-requests. The agent only sees the final response.

## Smart-contract enforced controls

- **Spend limits** — per-session caps via `set_spend_limit`.
- **Allowed destinations** — lock the facilitator to a list of endpoints or contracts.
- **Verify-work-before-pay** — the facilitator can require the work hash to match a commitment before settling.
