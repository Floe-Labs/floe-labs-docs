# Introduction

Floe is an **AI‑powered, intent‑based P2P lending protocol**. Users (or their AI agents) post **off or on‑chain intents** that are **matched** by independent bots and **settled on‑chain** as **isolated loan contracts** with optional **Hooks**.

* **Efficiency:** No idle pool capital → tighter spreads.
* **Flexibility:** Custom rates, terms, collateral rules, conditional execution.
* **Safety:** Per‑loan isolation; audited Hooks; oracle guards.
* **Autonomy:** AI agents for risk, automation, and governance tuning.

If you’re new, start with [**Mission**](docs/about/mission.md) and [**Quick Start**](docs/getting-started/quick-start.md).
