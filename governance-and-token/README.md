# Governance & Token

The path to decentralized governance of the Floe protocol.

## In This Section

- [Governance](../docs/governance/governance.md) - Protocol governance phases and mechanisms
- [Token Economy ($FLOE)](../docs/governance/token.md) - Token utility and distribution

## Current State (Phase 0)

Floe is currently in **Phase 0: Multisig Guardianship**

- Protocol upgrades via timelocked multisig
- Parameter changes require governance approval
- Emergency pause capabilities for security

## Governance Roadmap

| Phase | Description | Status |
|-------|-------------|--------|
| Phase 0 | Multisig guardianship | **Current** |
| Phase 1 | Token-holder DAO | Planned |
| Phase 2 | AI-assisted governance | Future |

## What Can Be Governed

- Protocol parameters (LTV limits, fees, oracle settings)
- Market creation and token listings
- Hook registry and whitelisting
- Treasury management and fee distribution
